# Remova 1.1.0

**Deep Uninstall Tool** — 深度卸载：找到程序 → 卸载 → 追踪关联 → 识别残留 → 解释风险 → 清干净。

相对 **v1.0.0**，本版本按产品 REDESIGN 全面收紧了信息层级、交互闭环与状态语义（不是「改颜色」）。

---

## 亮点

### 1. 深度卸载完整闭环（核心 UX）

```
选择软件 → 查看详情 → 开始卸载 → 官方卸载程序
    → 自动扫描残留 → 证据分类 → 你确认 → 可选备份 → 清理 → 报告
```

- 卸载确认框写清流程与勾选项：「卸载完成后自动扫描残留」
- 五阶段进度条：识别安装信息 → 启动官方卸载程序 → 扫描文件与注册表 → 分析关联项目 → 报告就绪
- 清理报告增加闭环说明与下一步建议；可打开备份目录 / 历史还原
- 软件详情栏（点行即开）：版本、发布者、路径、安装日期、占用、关联分桶（程序文件/配置/注册表/快捷方式/启动项）

### 2. 列表可扫、详情可信

- 列表只展示一行主信息 + 一行辅助信息（发布者证书 DN 不再撑高行）
- 每行最多 1 个高信号标签（无卸载命令 / 推荐清理 / 大体积）
- AI 从页面主角降为能力：「智能筛选」折叠展开 + 示例（大于 2GB 的 Adobe 等）；设置入口改为「模型设置 / 智能解释」

### 3. 系统项状态语义（专业系统工具）

| 页面 | 改动 |
|---|---|
| **启动项** | 「运行中」→ **已启用 / 已禁用**（开机是否执行）+ 来源（注册表/启动文件夹/Store/服务） |
| **服务** | 拆分 **运行状态** 与 **启动类型**；操作拆分 **停止 / 启动** 与 **禁用 / 启用**（停止 ≠ 禁用）；新增 `set_service_running` IPC |
| **计划任务** | **已启用 / 已禁用** + **上次运行 / 下次运行** |

- 管理列表图标改为中性灰；蓝色只用于主操作 / 状态 / 选中

### 4. 孤儿残留：「为什么相信你」

- 三级判断：可安全清理 / 建议确认 / 建议保留
- 每项可展开 **判断依据**：无对应卸载记录、含 exe、多文件、配置文件、安装根目录、最近修改时间等
- 顶部批量：全选可安全清理 / 全选建议确认 + 已选 N · 预计释放
- **默认只勾选安全项**，高风险与用户数据不默认勾选
- 页内扫描进度条 + 「上次扫描」状态；Toast 单通道，扫描中/完成不再叠两条

### 5. 风险层级

- 清理 / 强制清理 / 孤儿清理确认框首行标明 **风险层级**（低 / 中 / 高）
- 强制清理改为：先分析关联 → 展示风险 → 你确认后再删
- 残留列表中风险与「可安全清理 / 建议确认 / 将保留」一致

### 6. 工具箱信息架构

- 分组：**常用**（历史、备份还原、导出） / **高级工具**（强制清理、孤儿扫描、安装监控、右键菜单） / **系统与帮助**（模型设置、检查更新、Releases）
- 未选中软件时：提示「当前未选择软件 · 部分工具需要选择软件后使用」+「去软件列表选择」
- 需要软件上下文的工具明确标注「需先选中软件」，不再只是灰掉

## 安装包

| 文件 | 说明 |
|---|---|
| `Remova_1.1.0_x64-setup.exe` | NSIS 安装程序（推荐） |
| `Remova_1.1.0_x64_zh-CN.msi` | MSI 安装程序 |
| `Remova_1.1.0_x64-portable.zip` | 便携版，解压即用 |

系统要求：Windows 10 / 11（x64）。

## 安全与清理策略（相对 1.0）

- 清理前备份改为 **可选**（确认框默认不勾）
- 用户数据红线：Documents / Downloads / 同步冲突目录默认不删
- 共享运行库（VC++ / .NET 等）默认不勾；关键系统服务受保护不可禁用
- 服务器端清理门禁：伪造 IPC 标记无法绕过 user_data / shared / 系统路径保护
