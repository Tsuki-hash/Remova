# Remova 1.1.0

**Windows 深度卸载工具** — 找到程序 → 卸载 → 追踪关联 → 识别残留 → 解释风险 → 最后清干净。

相对 **v1.0.0**，本版本重点提升了卸载流程的完整度、信息展示的清晰度，以及系统项状态的准确性。

---

## 亮点

### 1. 深度卸载流程更完整

选择软件后即可在右侧查看详情（版本、发布者、路径、安装日期、占用空间、关联项目分桶），再决定是否卸载。

卸载时会：

1. 运行软件自带的官方卸载程序  
2. 自动扫描残留（程序文件、配置、注册表、快捷方式、启动项等）  
3. 将结果分为「可安全清理 / 建议确认 / 建议保留」  
4. 由你确认后再清理；备份为可选项（默认不勾选）  
5. 生成清理报告，可查看已删除 / 失败 / 跳过，并支持历史还原  

界面上会有清晰的阶段提示，让你知道当前进行到哪一步。

### 2. 软件列表更清爽

- 列表以「软件名 + 发布者 + 安装日期 + 体积」为主，不再被冗长证书信息撑高
- 高信号标签只保留最有用的提示（例如无卸载命令、推荐清理、大体积）
- 智能筛选改为可展开能力，可按自然语言查找软件（例如「大于 2GB 的 Adobe」）；模型相关配置入口为「模型设置」

### 3. 系统项状态更准确

| 页面 | 说明 |
|---|---|
| **启动项** | 显示「已启用 / 已禁用」（是否开机启动），并标明来源 |
| **服务** | 区分「运行状态」与「启动类型」；支持「停止 / 启动」与「禁用 / 启用」（停止 ≠ 禁用） |
| **计划任务** | 显示「已启用 / 已禁用」，以及上次运行、下次运行时间（如系统提供） |

### 4. 孤儿残留更可判断

- 按「可安全清理 / 建议确认 / 建议保留」分类
- 每项可查看判断依据（如无对应卸载记录、目录中含可执行文件、安装位置等）
- 支持按分类批量勾选；默认只勾选低风险项，避免误删
- 扫描状态显示在页面上，结果不会只靠右下角提示

### 5. 操作风险更透明

清理、强制清理、孤儿清理在确认时会标明风险层级；强制清理会先分析关联内容，再请你确认。

### 6. 工具入口更清晰

「更多」页按常用 / 高级工具 / 系统与帮助分组；部分工具需要先选中软件，会有明确提示。

## 安装包

| 文件 | 说明 |
|---|---|
| `Remova_1.1.0_x64-setup.exe` | NSIS 安装程序（推荐） |
| `Remova_1.1.0_x64_zh-CN.msi` | MSI 安装程序 |
| `Remova_1.1.0_x64-portable.zip` | 便携版，解压即用 |

系统要求：Windows 10 / 11（x64）。

## 安全说明

- 清理前备份为可选项，默认不勾选
- 文档、下载等用户数据目录默认不清理
- 共享运行库默认不勾选；关键系统服务受保护，不会被禁用
