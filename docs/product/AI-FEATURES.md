# Remova AI 功能说明

> 基线：**1.1.0（AI 决策层）** · 与 `package.json` 一致  
> 原则：**只解释不删除 · 规则结论始终在 · 模型可选增强**

---

## 1. 定位

AI 不是「角落里的开关」，而是 **每次深度卸载流程的决策层**：

1. 扫描结束自动出现 **清理结论**（本地规则；已配置模型则自动 AI 解读）
2. 结论操作联动列表（清理建议项 / 需确认 / 为何保留）
3. 软件列表旁 **Copilot**（自然语言筛选；未配置模型时用关键词回退）
4. 清理确认只保留 **压缩风险 + 保险箱**；完整叙事在扫描结论

---

## 2. 能做什么

| 能力 | 入口 | 说明 |
|---|---|---|
| 清理结论 | 扫描结果顶部 | 释放空间、可安全清 / 保留、最大风险；操作按钮 |
| 残留说明 | 残留行 `✦` | 对候选路径给出简短解释（有模型时） |
| 风险摘要 | 清理确认 | 1–2 条关键风险 + 备份说明 |
| Copilot | 软件列表旁 | 计划预览 → 应用列表 / 分析 / 批量（再确认） |

**AI 从不执行删除。** 勾选仍由 `defaultSelectable` 决定。

---

## 3. 配置

**更多 → 详细说明**

| 服务商 | 说明 |
|---|---|
| 本地 Ollama | 数据不出机 |
| OpenAI 兼容 API | 自定义 baseURL + 模型 |
| Anthropic | Messages API |

配置：`%LOCALAPPDATA%\Remova\ai-config.json`（Key DPAPI 加密，不回传前端）。

未配置时：结论卡显示「本地规则」，并提示「启用更易懂的说明」。

---

## 4. 隐私

- 默认 **不发送** 完整安装路径；开启后仅脱敏路径（用户名打码）
- 可发送：证据标签、风险等级、类型计数
- HTTP 超时 12 秒；响应 TTL 缓存；批量 explain 上限 12 条

---

## 5. 实现

- 后端：`src-tauri/src/ai.rs`
- 结论卡：`src/components/CleanupConclusion.tsx`
- Copilot：`src/components/CopilotPanel.tsx`（无 AI 时 `ruleParseFilter`）
- 自动解读：`App.tsx` 在 scan 完成且 `aiEnabled` 时调用 `runAiExplain`

---

## 6. 用户可见边界

- 结论徽章区分 **本地规则 / AI 解读**
- AI 文案旁标注「模型建议，以证据为准」
- 共享运行库 / 用户数据仍强制保护，AI 不能覆盖
