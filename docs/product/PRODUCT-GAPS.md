## 1. 产品定位建议

**「可解释、可回滚的深度卸载」** —— 比 Geek 更敢删（证据链 + 备份），比 Revo Pro 更透明（dry-run + safety 门禁 + 开源）。

优先把「**卸干净 + 敢卸 + 卸坏了能还原**」做到口碑级，再用安装监控 / 孤儿扫描做第二曲线。避免一上来做「IObit 全家桶」。

## 4. 用户日常痛点（体验债）

1. **勾选了却点深度分析没反应** — 已修（选中联动 + 禁用态）；同类「看起来能点」的坑优先消灭。  
2. **Admin 提权失败只显示 `ShellExecuteW runas failed code=5`** — 应映射为人话（UAC 拒绝 / 策略限制 / 已是管理员勿重复点）。  
3. **占用列大量 `—`** — `EstimatedSize` 缺失时应异步估算安装目录大小（可缓存、可取消）。  
4. **安装日期很多空** — 可回退 exe 修改时间 / 目录创建时间（UI 标明「约」）。  
5. **搜索只有关键字** — 缺「按发布者 / 来源 / 大于 1GB / 最近安装」过滤。  
6. **清理结果信息密度低** — 用户更关心：删了什么、释放多少、要不要重启、失败项怎么办。  
7. **高风险沟通** — safety 有，但 UI 需保证高风险「一眼危险」且默认不勾。

## 6. 建议实施顺序

```text
P0-3 错误文案（小、体感强）
  → P0-2 体积估算（支撑「释放空间」心智）
  → P0-4 批量进度
  → P0-1 UWP 覆盖
  → P1-4 还原 UI → P1-2 管理台 → P1-1 强制卸载 → P1-3 系统入口
  → P2 按用户反馈再排序
```

每项实施前建议：

1. 在本表勾选「进行中」并写子任务；  
2. 走 compose 规格或独立小 PR；  
3. 完成后更新 `docs/product/PARITY.md` / 验收清单，回填本文件状态与日期。

---

## 7. 明确不做 / 暂缓

| 项 | 原因 |
|---|---|
| 浏览器插件深度清理 | 与卸载主路径无关，易变成安全/隐私争议 |
| 系统垃圾清理全家桶 | 偏离「深度卸载」定位 |
| 无授权静默装监控驱动 | 法律与信任风险；P2 安装监控需用户显式开启 |
