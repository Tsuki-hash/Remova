## 1. 修复复核方法说明

本轮不复述代码全貌，聚焦**验证"声称已修复"是否属实**：

1. **代码证据**：每个修复项定位到具体文件与行为，确认实现与第一轮建议一致（而非表面改动）；
2. **测试实证**：实际执行 `cargo test --lib`（56 用例）、`npm test`（6 用例）、`npm run build`（tsc + vite），不以"看起来改了"为准；
3. **交叉核对**：CHANGELOG 声明与真实代码逐条对照（发现全部声明属实，无虚报——仅冒烟测试注释与行为矛盾一处）；
4. **新问题扫描**：对新提交代码（约 2,400 行新增/修改）做一轮增量走查。

> 说明：本评审环境为受限沙箱（无法写入 `C:\ProgramData`），该限制本身即暴露了 NEW-1 的环境依赖问题；下文涉及"本机实测失败"处均标注了此背景。

## 5. 新发现问题

### NEW-1【P1】pipeline_smoke 集成测试不封闭，且注释与行为矛盾

- **位置**：`src-tauri/src/pipeline_smoke.rs:1-3`（头注释）、`:75-83`（触发点）；根因在 `backup.rs:8-11`（全局 `backup_root()`）与 `executor.rs:245-251`
- **现象**：本机实测失败——测试调用 `run_full_cleanup(backup_enabled: true)`，内部经全局 `backup_root()` 向**真实** `C:\ProgramData\Remova\Backup` 创建会话，受限环境（非管理员/锁定 ACL/沙箱）直接 os error 5。
- **三个具体问题**：
  1. **写真实系统位置**：`backup_root()` 无注入点（无环境变量覆盖、无参数传递），测试无法重定向到临时目录；
  2. **触发真实系统还原点**：`run_full_cleanup` 在 `backup_enabled` 时无条件调用 `SRSetRestorePointW`（executor.rs:246）——管理员机器上每次 `cargo test` 都会尝试创建名为 "Remova: RemovaPipelineSmoke" 的真实还原点（受 Windows 频率限制，但首次会真实创建），污染开发者系统；
  3. **头注释虚假陈述**：文件头声称 *"Uses a temp directory only; never touches real uninstall keys or ProgramData backup root"*，与实现完全矛盾（文件末行注释反而承认了 ProgramData 会话）——这正是第一轮 CODE-6 批评过的"注释误导维护者"问题的复发。
- **影响**：CI（管理员环境）大概率绿，掩盖问题；但任何受限环境下 `cargo test --lib` 必红，且管理员开发机承受真实副作用。
- **修复建议**（半天工作量）：
  1. `backup_root()` 读取环境变量覆盖：`std::env::var_os("REMOVA_BACKUP_DIR")` 优先；
  2. `FullCleanupOptions` 增加 `restore_point: bool`（默认 true）；
  3. 冒烟测试设置临时 `REMOVA_BACKUP_DIR` + `restore_point: false`，并修正头注释。

### NEW-2【P1】未提交的版本号降级，与发布历史冲突

- **位置**：工作区未提交改动——`package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json` 三处 `1.1.1 → 1.1.0`
- **问题**：
  1. 版本历史中 **1.1.0 已发布**（commit `adb4413` "release 1.1.0"），**1.1.1 也已存在**（`fd6cd9e`）；把本轮大规模修复（CHANGELOG 列了 27 条 Added）记在 1.1.0 名下降级发布，会与既有版本/Tag 冲突，语义上也说不通；
  2. 按 CHANGELOG 自身声明采用 Keep a Changelog 语义，这轮含新功能（备份会话管理、监控闭环、虚拟化）应升 **1.2.0**；
  3. 三文件**未提交**——release.yml 依赖版本号打 Tag，当前状态下无法走发布流程。
- **修复建议**：三处版本改为 `1.2.0`，CHANGELOG 段落名同步改为 `[1.2.0] - 2026-09-14`，随后提交。若确有回退理由，需在 CHANGELOG 说明。
